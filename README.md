## 📌 Descripción
**miTienda** es una aplicación desarrollada en Java diseñada para gestionar productos, inventario y ventas de manera eficiente. Este proyecto forma parte de mi portafolio personal de desarrollo de software para demostrar principios de Programación Orientada a Objetos (POO) y estructura de proyectos.

---

## 🚀 Características Principales

- **Gestión de Productos:** Registro, actualización y consulta de inventario.
- **Módulo de Ventas:** Procesamiento de órdenes y cálculo de montos.
- **Diseño Orientado a Objetos:** Implementación de abstracción, encapsulamiento, herencia y polimorfismo.
- **Manejo de Estructuras de Datos:** Organización eficiente de datos en memoria.

---
