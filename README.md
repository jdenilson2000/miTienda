## 📌 Descripción
**miTienda** es una aplicación desarrollada en Java diseñada para gestionar productos, inventario y ventas de manera eficiente. Este proyecto forma parte de mi portafolio personal de desarrollo de software para demostrar principios de Programación Orientada a Objetos (POO) y estructura de proyectos.

---

## 🚀 Características Principales
* **Gestión de Productos:** Registro, actualización y eliminación de artículos del catálogo.
* **Control de Inventario:** Monitoreo de stock disponible en tiempo real.
* **Módulo de Ventas:** Procesamiento de compras y cálculo de importes.
* **Estructura Limpia:** Aplicación de buenas prácticas de código y diseño modular.

---

## 🛠️ Tecnologías Utilizadas

* **IDE:** IntelliJ IDEA
